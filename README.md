🎓 Student Management System & Data Structures

A Java project demonstrating Data Structures concepts and Object-Oriented Programming through practical applications.

🚀 Project Features

1. Student Management System

- Add students.
- Display student records.
- Search for students.
- Update student information.
- Delete student records.

2. Data Structures & Array Operations

- Arrays.
- Array Traversal.
- Array Insertion.
- Array Deletion.
- Linear Search.
- Array Manipulation.

🛠️ Technologies Used

- Java
- Data Structures
- Object-Oriented Programming (OOP)
- Arrays
- Classes and Objects
- Encapsulation

🎯 Learning Objectives

- Understand fundamental Data Structures.
- Practice array operations.
- Apply searching and insertion techniques.
- Develop problem-solving skills.
- Apply OOP concepts in Java.

▶️ How to Run

javac *.java
java MMain
